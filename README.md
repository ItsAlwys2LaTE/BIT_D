# BIT Durg Website Redesign

A clean, uncluttered, and minimalist redesign of the BIT Durg website, created as a submission for a competition. 

## Our Team
This redesign was conceptualized and developed by:
* **Adnan Khan**
* **Anupam Sharma**
* **Garv Thakre**

## Tech Stack
The application is built using modern web technologies to ensure a fast, responsive, and interactive user experience:
* **Frontend Framework:** React 18
* **Build Tool:** Vite
* **Routing:** React Router DOM
* **Animations & Effects:** Framer Motion, Typed.js
* **UI Components & Icons:** FontAwesome, Hamburger React
